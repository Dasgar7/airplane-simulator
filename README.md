# Airplane Simulator

3D open-world pilot game. Fly between countries, visit people who need a delivery, and get paid.

## Play

- Desktop: WASD / arrows to pitch and roll, Shift throttle up, Ctrl throttle down, Space visit when near a beacon.
- Mobile landscape: on-screen stick + throttle + Visit button.
- Install as a PWA (Add to Home Screen / Install app).

Progress (cash and completed jobs) saves in the browser.
